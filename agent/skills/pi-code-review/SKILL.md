```
自检 → 确定审查范围 → 确定性检查 → 人工检查清单 → 验证要求 → 分级报告
```

```bash
# 3. 运行确定性检查
# 脚本输出：git 卫生、语法检查、可疑模式

# 4. 人工检查清单
# 逐项核对：正确性、安全、资源、并发、回归、可维护性

# 5. 验证要求
# 运行测试、类型检查、lint

# 6. 分级报告
# 按 HIGH/MEDIUM/LOW 分级输出
```

## 约定

- **只读**：审查过程不改任何文件。用户明确要求"修复"后才动手，且修复前列出计划。
- **敏感信息脱敏**：报告密钥/凭据时只报位置，不显示内容。
- **不确定的先验证**：对可疑点用 grep/阅读代码确认，不凭空猜测。
- **测试先行**：审查涉及的功能改动，必须确认测试已运行并通过后再报告完成。
