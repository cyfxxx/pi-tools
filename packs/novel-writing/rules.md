# 规则层：一致性 · 叙事 · 输出 · 参数

本文是全部生成行为不可违背的执行条例（整合自 tianming `codex/` 与 `constants/`，去修辞、留语义）。生成行为与规则冲突时，遵循本文；用户知识库文件与本文冲突时，项目内的知识库时效性更高。

## 一、一致性条例（六条）

| # | 条例 | 含义 | 违例示例 |
|---|---|---|---|
| 1 | **因果律闭环** | 任何结果都有前置因，任何因都有可见果 | 新能力凭空出现 |
| 2 | **代价守恒** | 能力/资源/关系的变化必须付出代价，不白嫖 | 升级不损耗、背叛无后果 |
| 3 | **角色烙印** | 行为与动机符合角色既定烙印，变化有过程 | 沉默角色突然话痨且无铺垫 |
| 4 | **实体时序** | 时间线、年龄、事件顺序精确递推，不倒退 | 第二卷起始章序不等于上卷末+1 |
| 5 | **视角唯一** | 单章单一 POV，不越界全知 | 主角心里蹦出配角心声 |
| 6 | **关系向量** | 关系变化有源有果，双向记录 | 化敌为友缺转折事件 |

**一致性检查清单**（每次体检/审查输出只分四类：硬伤 / 风险 / 伏笔状态 / 通过项）：

- 死人、退出角色不得再活动（除非有设定来源）
- 信息传播边界：A 不知道的事不能出现在 A 的认知里
- 禁止"全知任务/救场任务"：没有来源的临时解围、追溯奖励
- 禁止判定漂移：同一规则在不同章节对不同对象不同裁决
- 禁止木偶驱动：角色行为只服务于剧情需要而违背其动机

## 二、叙事结构

| 维度 | 规则 | 说明 |
|---|---|---|
| 哲学母题 | 一部作品只服务 1-2 个母题 | 反复回响，不主题杂乱 |
| 主题回响 | 关键意象/台词在卷首尾回扣 | 形成结构内闭环 |
| 熵增抑制 | 信息供给量有上限，别一鼓作气倒完 | 全卷信息供给约 3 成缓冲（见可调参数） |
| 场景呼吸法 | 张弛交替，高潮后必给缓冲 | 连续紧绷会钝化情绪 |
| 信息分级解密 | 单章解密上限约 30% | 保留 70% 继续牵引 |
| 宏观节奏 | 起 20 / 承 30 / 转 30 / 合 20 | 可调参数，按体量修改 |

## 三、输出纪律

1. **模板即法律**：规划/目录/体检/存档绑定的 Markdown 表格不得更改、删减、调换列；不得省略字段或用省略号/缩写糊弄。这是跨批次产物可机器校验的基础。
2. **引脚保真**（载体 DNA）：悬念钩子从目录 → 草案 → 正文逐级锁定。**验证的核心是【意图保真】而非【字面保真】**：钩子归属于第 N 章，则该章只能描述已形成的状态，禁止未来时态预支。
3. **仪表盘**：正文结尾附【叙事资源仪表盘】+ 续章指令，形成闭环。
4. **质量门**：输出前过一遍 `craft.md§去AI指纹` 的无情审查。

## 四、冲突值量化

用于衡量"本章冲突/剧情烈度"是否配得上关键节点，可脚本化或人工估分：

```
冲突分值 = 1 + Σ(权重 × 触发次数)
```

| 事件 | 权重 |
|---|---|
| 核心角色状态改变 | +8 |
| Tier-1 伏笔（主线级）兑现/转折 | ±8 |
| Tier-2 伏笔兑现/转折 | ±5 |
| 奇点事件（每卷≤3 次） | +5 |
| 普通冲突/对抗 | +1 |

- 分值 ≥ 16 视为"五星核心峰值"：该章应配置对应的篇幅与缓冲
- 用于正文前判断：若打算把低分值场景写成大高潮，先重审计划

## 五、可调参数（默认值，非铁律）

以下为整合版收敛后的默认值。上游为网文定型参数，不同体量/题材可改；改动后在体检时复核知识库一致性。

| 参数 | 默认 | 说明 |
|---|---|---|
| 单章净字数（不含标点） | 3500–4000 | 下限 3500，上限 4000 |
| 全卷信息缓冲比 | 37%（可用 30% + 校准 7%） | 别把信息一次性倒完 |
| 目录批次 | 目标 30，上限 50 | 分阶段规划，见 `engineering.md` |
| 叙事断点扫描窗口 | 5 章 | 规划时找断点/章节切割锚 |
| 沉睡伏笔激活阈值 | 50 章 | 超期未回收 → 体检警报 |
| 奇点事件配额 | 3 次/卷 | 全书级事件，限量 |
| 跨卷伏笔回收率下限 | 60% | 跨卷必须有应收尽收 |
| 单章信息解密上限 | 30% | 见"信息分级解密" |
| 宏观节奏 | 起 20/承 30/转 30/合 20 | 按卷内章数分配 |
| 章节超载容忍度 | 1.05 | 单章相对目标字数允许浮动范围 |
