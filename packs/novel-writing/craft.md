# 技法层：文风溯源 · 写作戒律 · 渲染 · 去 AI 指纹

整合自 tianming `aesthetic/` + ani-book `chinese-novel-humanization.md`。文风的最终归宿永远是《文风样本.md》。

## 一、文风溯源（style-genesis）

一切输出的"文气"须趋近《文风样本.md》。做法：

1. 把《文风样本》分解为**风格基因**：常用词汇、句式长度、转场方式、叙述距离（内外视角）、对话习惯、比喻偏好
2. 用这些基因重组本次任务内容——不是复读样本原句
3. 口语化判定：样本若口语化，启用口语要素——日常高频词、适度语气词（啊/哎/嘛/呢）、句式省略、生活化比喻（忌典故堆砌）、**人设匹配**（不同身份/阶层/年龄用各自口径）
4. 每章提炼"文风执行表"：当前版本、场景模式、硬规则、相关软倾向、角色声音覆盖、高风险表达；执行表进上下文即可，不要把范文全文带进正文生成

## 二、写作戒律（writing-edicts）

**戒律一 · 打破常规**：允许跳跃联想与话题切换的断裂感；用新颖比喻，坚决避开陈词滥调；接纳"不合逻辑的真实"——情绪驱动下的矛盾与复杂。

**戒律二 · 凝练语言**：
- 动词优先：用一个精准强力的动词，取代"平庸动词+副词"——"他**冲**了过去"而非"他非常快速地跑了过去"
- 多用反问：以问句制造悬念与张力，而非平铺直叙——"这种事，怎么可能成？"而非"这件事是不可能成功的"

**优先级**：初稿阶段挂起戒律二（给情节展开空间）；精修/字数打磨阶段重新启用；扩写救字数时搁置戒律二（字数下限优先）。

## 三、渲染技法（rendering-tools）

1. **人物递进描写**：不一次性堆完外貌，按"整体印象 → 动作细节 → 情绪化特征"随场景递进揭示
2. **潜台词对话**：对话承担信息与情绪双重任务，说一半藏一半；不同身份用不同风险偏好说话
3. **五要素打斗/动作**：环境、动作、感官、心理、时间五个维度交错，避免直线流水账
4. **感官优先于思考**：紧张/恐怖场景渲染以感官细节优先，禁大段心理分析独白

## 四、去 AI 指纹

### A. 黑名单（最终输出守门员，一票否决）

| 类 | 典型 | 处理 |
|---|---|---|
| 套路化连接词 | 然而 / 与此同时 / 众所周知 / 值得一提 | 换更自然的过渡或直接删 |
| 万能形容词 | 无与伦比 / 美轮美奂 / 叹为观止 | 用具体指向的细节替代 |
| 客观陈述腔 | 需要注意的是 / 不难看出 / 显而易见 | 改从角色视角观察 |
| 凑字副词 | 非常 / 十分 / 相当 / 极其 | 用精准动词替代 |
| 比喻陈词滥调 | 眼睛像星星 / 笑容像阳光 / 心情像过山车 | 换新颖意象 |
| 排比堆砌 | 无内在递进的三段式排比 | 拆散或删 |
| 大段心理分析 | 紧张场景里的长篇心理独白 | 感官优先（见渲染技法） |

净化重构最多 3 次；3 次仍命中 → 报告污染片段，请用户裁决。

### B. 人类化二稿（重写方法）

当正文"机器味"明显时，做一轮二稿（吸收 ani-book 方法）：

**先锁定不可改**：章节合同、已发生事实、人物硬事实、信息边界、伏笔窗口、物件归属、时间顺序、章末钩子。**禁止**用错别字/病句/隐形字符/伪造经历/改剧情来制造"人味"。

**只修反复出现且影响阅读的问题**（同类问题连续出现才动，单次出现不算问题）：
1. 否定式并列与揭示骨架：`不是X，而是Y`、尾随否定短句、先排除再揭示——除非人物误判/审讯/反讽确有职责，否则直接从行动写起
2. 格言化旁白："权力是……""命运从不……"这类可脱离场景传播的句子
3. 解释性推进：叙述者替读者解释"意味着什么"，没让动作/对话承担
4. 段落模板：每段短句开头→解释→小转折→收束，或全章段落长度过齐
5. 均质声音：主角/母亲/姐姐/对手都用同一套冷静完整机敏的句式
6. 泛化感官与抽象词："压迫感/命运/重量/涟漪"代替可触摸的空间物件身体反应
7. 悬空判断："事情很严重""局面复杂"——每个保留的判断都要有"谁在何处看见/做出/承担"
8. 重复动作标签：同一角色的固定动作多次承担同一种情绪解释

**场景化手段**：让人物说"不完全正确"的话；用物件/停顿/被打断动作/他人反应承载情绪；保留一处不立即解释的观察等后文兑现；把否定-揭示改为"角色先选择、读者从结果得知"；合并过碎段落。

**验收**：重写后章节合同（主角主动性、必须事件、关系净变化、禁止越界、读者回报、章末钩子）全部仍成立；保留 `draft.md`，另存 `draft-humanized.md` 供对比。

### 中文网文适配

- 允许引号、破折号、短句与章末钩子——仅在机械堆叠时才修
- 不强制段落数/句长比例/对话比例；节奏服从场景，不服从指标
- 宫廷/历史/玄幻可用题材词；检查的是"词汇是否顶替了具体叙事"，不是删除题材语言
- 对话不必口语化到现代，也不必人人文雅；反映身份、目的、风险承受与关系
