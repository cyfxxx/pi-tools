# 微信小程序开发指南

覆盖从注册到发布的全链路要点，避免踩备案、类目资质、审核三类硬坑。

## 适用与不适用

- 适用：新建小程序项目、评估个人 vs 企业主体、跨端框架选型、备案与上架流程、审核被拒排查
- 不适用：小游戏专项（另有类目体系）、公众号/H5 开发

## 步骤

### 1. 注册账号，选定主体

1. 微信公众平台（mp.weixin.qq.com）注册小程序账号，获取 AppID；快速验证可先用「测试号」免注册
2. 主体选择决策：**个人**免费但无微信支付、类目受限（不能电商交易）；**企业**需微信认证（300 元/年），可开支付与完整类目
3. 部分类目需行业资质前置（如食品经营许可证），立项前先查目标类目要求

### 2. 技术选型

- 单端只发微信 → 原生（WXML/WXSS/JS/JSON），官方工具链最顺
- 多端（微信/支付宝/抖音）→ 跨端框架二选一：uni-app（Vue 系）、Taro（React 系）
- UI 组件库：Vant Weapp / WeUI / TDesign Miniprogram

### 3. 后端方案

- 自有服务器：request 域名必须 **HTTPS 且已完成 ICP 备案**，在 mp 后台配置合法域名白名单
- 免运维路线：微信云开发（云函数/云数据库/云存储），按套餐付费，无完全免费档

### 4. 备案（硬性门槛）

- **2023 年 9 月起新小程序必须完成 ICP 备案才能上架**；mp 后台「设置→小程序备案」入口提交，通管局审核 1–20 个工作日
- 备案期间可正常开发调试，不影响上传代码
- 已上架存量小程序未备案会被平台清退处理

### 5. 上架与审核避坑

1. 流程：开发者工具上传代码 → mp 后台提交审核 → 通过后发布
2. 高频拒审原因：类目与实际功能不符、缺少对应资质、诱导分享/关注、测试账号不可用（务必提供可登录的测试号）、页面空白或加载失败
3. 审核时长通常数小时至 1 天，被拒按驳回意见修改后重新提交即可，无需重复备案
