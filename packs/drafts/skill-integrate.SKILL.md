# 外部技能整合进 packs

适用：用户要求"去 GitHub 找 xxx 相关项目/技能""把 xxx 整合进 packs"。

## 步骤

1. **调研借鉴**
   - web_search / GitHub 搜索候选项目与技能，记录功能面、依赖重量、license、活跃度。
   - 输出候选清单与取舍理由；重大取舍先征求确认。

2. **本地摸底**
   - 通读 `packs/` 现有技能与 `packs/README.md` 索引，标出功能重叠项。

3. **三层归置**
   - 通用能力（≥2 个技能可复用）：提取到共享位置（lib/ 或通用技能）。
   - 专用能力：按领域分类存放为独立技能目录。
   - 繁重/不常用功能（重依赖、需外部服务、低频）：不落地实现，只在 README 待办区记录来源与用途。

4. **整合纪律**
   - 与现有技能或远程更新整合时以合并优化为主，禁止直接覆盖。
   - 保留本地已有增强：中文说明、pi 工具适配、缓存友好改造。

5. **收尾**
   - 更新 `packs/README.md` 索引与技能 frontmatter（name/description，不带时间戳）。
   - 记录整合说明：来源、纳入/未纳入项及原因；有长期价值的结论 memory_store 入库。
