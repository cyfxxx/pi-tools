# 每日整体复检

对 pi 前一日运行情况做整体层面检查，输出 ok 或异常项清单。**只读为主、不深入探索**，防 token 浪费（参考一轮 tools 6-12 个、out ~500 tokens）。

## 前置

- 后台独立会话执行（tmux_run），勿改配置
- 工作目录 `cd /root/.pi`

## 步骤

1. **缓存健康**：`node scripts/usage-stats.mjs 2>&1 | tail -6`
   - 看命中率（参考正常 ≥95%）、断裂次数（A/B 类）、浪费 tokens
2. **健康日志**：检查当日 alert 条件是否触发，无触发结论 ok
3. **知识订阅产出**：确认最近几天 knowledge-fetch.py 是否有新增产出
   - 连续多日无产出 → 先查触发机制（任务是否真的运行），不默认脚本坏了
4. **lesson-miner 异常线索**：有新异常才考虑沉淀 solutions，无则跳过
5. **存储水位与任务记录**：memory_stats 看存储/条目数，对照任务记录条数
6. **汇总**：一条 bash 聚合完成全部检查项；输出仅"ok / 异常项清单"两类结论；异常项创建后续任务处理，不在当轮深挖

## 参考阈值（2026-08-24 实测正常值）

- 缓存命中 96.9%、断裂 1 次（A 类）、浪费 36K tokens → 正常
- 存储 0.26MB/2MB、条目 514 → 健康
