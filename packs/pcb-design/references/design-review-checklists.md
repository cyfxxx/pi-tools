# 设计审查清单（design review checklists）

布局/布线方法论与量化约束、数据手册结构化提取、原理图细分检查项、DFM/Gerber/BOM 核对。原创提炼自公开硬件工程实践（2026-08 补充），供审查现有工程或指导从零设计时对照。与 SKILL.md 最小审查清单挂接，本文件是细粒度展开。

## 布局审查（Placement）

布局四步法（顺序即优先级，前一类是锚点不可移动）：

1. **结构件定位**：连接器（USB/HDMI/电源）与安装孔按结构图锁定；限高区先落 Keep-out
2. **功能分区**：电源/数字/模拟/射频/接口分块，模拟与数字严格分离，区间留隔离带
3. **关键器件优先**：MCU 靠板心近主接口；电源芯片近输入且远离模拟区；晶振紧贴时钟引脚；DDR 等距环绕控制器；去耦电容紧贴电源引脚
4. **按信号流向排列**：输入→输出单向流动，避免折返，高速路径最短

量化约束（审查阈值，超出即列为 finding）：

| 项 | 建议值 |
|---|---|
| 晶振到时钟引脚 | ≤10mm |
| 去耦电容到电源引脚 | ≤2mm |
| 工艺边 | ≥5mm |
| 高速线到板边 | ≥3H（H 为层间距，见 core-workflows EMC 节） |

其余检查：连接器与结构一致、功能区无交叉、散热器件留空间、差分对预留等长绕线空间、元件间距满足贴装工艺。

## 布线审查（Routing）

三步法：先 BGA/QFN 扇出（过孔换层引到内层）→ 关键信号优先（时钟最短、差分等长等距、DDR 等长端接、射频 50Ω 远离数字、电源宽走线）→ 普通信号就近、少过孔、避与高速平行。

量化规则表：

| 规则 | 要求 |
|---|---|
| 阻抗 | 单端 50Ω、差分 100Ω（或按协议），公差 ±10% |
| 等长 | DDR 组内 ≤50mil；差分 P/N ≤ 上升沿 1/4 |
| 间距 | 高速 ≥3W；差分对间距 ≥4W |
| 回流路径 | 高速线下参考平面完整；换层过孔旁加地过孔 |
| 铜皮 | 地平面不分割；空白区铺地 |

自查：无飞线、高速无跨分割/无参考平面切换、去耦路径最短、电源线宽满足电流承载、无锐角（135°/圆弧）、3D 视图无干涉。

## 数据手册六章节提取框架

datasheet 同步后按此结构化提取，每章对应验证点：

| 章节 | 提取 → 用于 |
|---|---|
| Absolute Maximum Ratings | 电压/温度极限 → 校验电源域与瞬态是否越界 |
| Recommended Operating Conditions | 正常工作范围 → 所有工作点必须落在其内 |
| Pin Description | 引脚功能/方向/电平 → 引脚级验证、未用引脚处理依据 |
| Typical Application Circuit | 外围拓扑与推荐值 → 原理图设计的对照基准 |
| Layout Guidelines | 走线/去耦/散热焊盘/接地要求 → PCB 审查对照 |
| Package Outline | 焊盘/热焊盘尺寸 → 封装库核对唯一依据 |

前两章缺失时，引脚级/电气结论降级 consistency only（对齐 SKILL.md 证据分级原则 #1）。

## 原理图评审细分项

SKILL.md 最小清单"原理图分析"的展开，按模块核对：

- **电源**：各路电压正确；上电时序（Power Sequencing）满足要求；输入/输出电容按手册配置；使能/复位时序正确；功耗在芯片额定内
- **复位**：上拉/下拉存在；RC 延时满足芯片要求；有手动复位
- **时钟**：负载电容匹配晶振规格；晶振靠近时钟引脚；有源晶振使能/待机引脚处理
- **存储**：DDR 端接电阻正确；Flash/eMMC 片选/使能引脚处理；总线拉电阻
- **通信**：USB DP/DM 90Ω 差分标注；以太网 PHY 端接；RS-485 端接+偏置电阻
- **IO 电平**：跨电压域有电平转换；开漏输出有上拉；输入耐受匹配
- **保护**：电源入口 TVS/保险丝；外部接口 ESD；热插拔防浪涌
- **未使用引脚**：每个引脚处理方式（NC/悬空/上拉/下拉）有手册依据

## DFM 细化（下单前）

工艺能力确认（线宽/线距/孔径/层数/板厚/表面处理与板厂核对）之外的两类生产性检查：

- **生产友好**：拼板合理、工艺边足够、Mark 点已放置、测试点可探测、V-Cut/邮票孔分板可行
- **装配友好**：元件方向统一、钢网开孔合理、无高大元件遮挡贴片（阴影效应）

## Gerber 层命名速查

解析 fab 目录快速目检文件集缺层（RS-274X 惯例命名）：

| 后缀 | 层 | 后缀 | 层 |
|---|---|---|---|
| .GTL | 顶层铜 | .GBL | 底层铜 |
| .G1~Gn | 内层铜 | | |
| .GTS | 顶层阻焊 | .GBS | 底层阻焊 |
| .GTO | 顶层丝印 | .GBO | 底层丝印 |
| .GTP | 顶层锡膏 | .GBP | 底层锡膏 |
| .GKO | 板框 | .GML | 铣槽/开孔 |
| .DRL | 钻孔（Excellon，含通孔/盲埋孔） | | |

注意：厂家/软件命名未必遵循此惯例（KiCad 输出为 `-F_Cu.gbr` 等自有命名），权威核对以 gerbonara 解析的层语义为准，此表用于快速目检。参考完整性：四层板应有 GTL+G1+G2+GBL；BGA 需锡膏层；槽孔需 GML 或钻孔内 slot。

## BOM 必备字段

位号、Value、Footprint、MPN（制造商料号）、**SPN（供应商料号）**、Quantity、**Alternate MPN（替代料）**。

后两项是供应链风险审查点：无 SPN 难以与渠道库存核对下单；无替代料的唯一源器件是断供风险，关键器件应有第二来源。导出命令见 core-workflows，字段可按工程 BOM 模板支持情况扩展 SPN/Alternate 列。
